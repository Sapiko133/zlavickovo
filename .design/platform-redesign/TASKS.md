## Working Rules

- Pred každým rezom, ktorý mení Next.js API, routing, caching, metadata alebo image správanie, prečítať relevantnú lokálnu dokumentáciu v `node_modules/next/dist/docs/`. Projekt používa Next.js 16.2.9.
- Pred úpravou skontrolovať dirty diff dotknutých súborov a zachovať nesúvisiace používateľské zmeny.
- Každý rez končí minimálne `npx tsc --noEmit`, `npm run lint` a cielenými testami uvedenými pri úlohe. Build spustiť po každej routovej, konfiguračnej alebo väčšej UI zmene.
- Žiadna DB migrácia sa nespustí v produkcii, kým Neon opäť nepovolí read-only audit, kontrolu veľkosti tabuliek a query planov. Migrácia musí byť idempotentná a mať bezpečný rollout.
- Žiadny verejný badge alebo ranking sa neimplementuje skôr, než jeho dátové pravidlá prejdú testami.
- Každý dokončený rez má vlastnú viditeľnú používateľskú alebo administrátorskú hodnotu a dá sa samostatne vrátiť.
